# Console port requirements

- The user wants the complete original console game ported, not a prototype delivery.
- Do not launch a visible client, show screenshots, or present previews until the
  full port is complete. This is an explicit user preference from September 7, 2026.
- Continue implementation and nonvisual verification. Keep status accurate; passing
  tests for one subsystem do not establish full-game completion or visual parity.
- Reuse only general libraries/platform/renderer support from the parent project.
  Port original gameplay systems from the supplied console archive. Keep changes
  inside this folder and retain source provenance and reference comparisons.
