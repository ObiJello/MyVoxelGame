## Parity invariants (additions to BASELINE_2026-08-07 list, all re-affirmed)

- Util.shuffle = reverse Fisher-Yates; stable sort by selection_priority
  (jigsaw); alphabetical Identifier registry order; structure-vs-feature
  setFeatureSeed index counter collision semantics (vanilla behavior).
- All structure RNG is LegacyRandomSource; `WorldgenRandom.next(bits)`
  switches semantics on the inner source type.
- Weighted-selection CASCADE in fortress/stronghold piece tables (no break
  on factory-null); draw-order rules (args draw before callee; unsequenced
  C++ operands must be hoisted; Java Math.round(float) = floor(x+0.5f)).
- WorldGenerationContext heights clamp to NOISE-SETTINGS height (nether/end
  = 128), not dimension height (256) — carvers, features, anchors.
- Java getMaxY() is INCLUSIVE vs C++ exclusive (±1 on transcribed guards).
- hasSkyLight() is false exactly for legacy_random_source dimensions —
  gates the MushroomBlock canSurvive fallback during worldgen.
- Java `.replaceable()` block flags matter (roots/sprouts/fire/soul_fire
  yes, fungus no); every block a structure places must be registered with
  its full Java property set (propertyless registrations dump wrong).
- EndIslandDensityFunction::mapAll must be visitor.apply(this) — a fresh
  copy silently reseeds to 0.
- featuresPerStep is PER-DIMENSION, keyed on the generator's possibleBiomes.
- Template missing-file → EMPTY template semantics (vanilla datapack
  references a nonexistent nbt); structure exceptions abort loudly (worker
  exception = pipeline hang otherwise).

  "error" substring) — always `cd minecraft_terrain/build` first.

  before trusting dumps — a 127 once produced a stale-dump bogus diagnosis.
- Never rebuild while a regression/gate background run is in flight.

  add a fourth: user gaming during capture).
