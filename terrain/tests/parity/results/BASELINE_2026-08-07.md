  (block states with properties + biome quarts + WS/OF WG heightmaps),
  C++ byte-deterministic on every combo.

  (`coverage_report.py` gate).

  — random 64-bit seeds, random centers incl. ±60k far regions, fresh Java
  every time. Two REAL pre-existing bugs were found this way after the golden
  net was already 100% green (see "Spot-check catches" below); both fixed,
  both regions promoted to goldens.
- **Performance: 18.77 ms/chunk** (r10 @ origin, seed 12345, median of 3,
  idle machine) vs **23.33 ms/chunk** pre-optimization baseline = **-19.6%**.
  Java reference: 41.96 ms/chunk (bulk, phases 3-6 — not apples-to-apples,
  C++ includes features). RSS 1.09 GB (was 1.05 GB with permanent leaks;
  now leak-free per-chunk with bounded ownership bookkeeping).
- **Leaks: zero per-chunk leaks** (`leaks --atExit`: 71.2 MB / 603k
  allocations leaked per single-chunk run → 1.13 MB, all one-time registry
  bootstrap singletons).

## Spot-check catches (both pre-existing, invisible to 88 green goldens)

1. **Hanging mangrove propagule not removed** when a later tree's trunk
   replaces its supporting leaf with a log. Java: MangrovePropaguleBlock
   updateShape → !canSurvive → air on any face update. C++ shape pass now
   handles it (TreeFeature.cpp, name-gated virtual canSurvive).
2. **cave_air silently dropped in empty sections** —
   `ProtoChunk::setBlockState`'s all-air-section fast path used the broad
   `isAir()` (true for cave_air/void_air) where Java tests plain
   `state.is(Blocks.AIR)`. Any cave_air written into an untouched sky section
   vanished; visible as a surface lava lake (rarity 1/200) losing its air
   dome above y=63. Fixed with `state->is(m_airBlock)`.
   **TRAP: isAir() and is(AIR) are not interchangeable.**

## Parity invariants (re-affirmed, unchanged)

- `-ffp-contract=off -fwrapv`; no fast-math/reassociation; division stays
  division; the inert `#pragma omp simd` stays inert.
- RNG draw counts (UniformInt.sample draws even when min==max; per-feature
  setFeatureSeed reseeding).
- Iteration orders: JavaHashSet red-black-tree bins, BlockPos.betweenClosed
  x-fastest, Direction.Plane.HORIZONTAL = N,E,S,W, DiscreteVoxelShape
  forAllFaces Z/Y/X axis passes, tag-file order for orderedBlockTagValues.
- FEATURES never parallelized; ConsecutiveExecutor semantics untouched.
- Blocks are registry singletons (registerBlock throws on duplicate) — the
  foundation for all pointer-identity compares.
- ProtoChunk empty-section skip is plain-air only (see trap above).
- Unfilled-section biome queries return the `Biomes::get("")` placeholder,
  never null — carver seeding probes chunks up to ±8 away and skips a source
  chunk entirely on a null biome.

## Verification infrastructure (all in tests/parity/)

- `run_regression.sh --tier 0|1|2|all [--perf]` — Java-free gate from 90
  gzipped goldens + MANIFEST.json (sha256, jar provenance). Tier 0 ≈ 1 min,
  tier 1 ≈ 5 min, tier all ≈ 50 min.
- `run_spot_check.sh --count N` — fresh-Java random-seed overfit detector.
- `run_acceptance.sh [--fresh-java]` — the full held-out acceptance run.
- `coverage_report.py` + `biome_search` — 54/54 biome coverage gate.
- `perf/capture_perf.sh` + `perf/compare_perf.py` — median-of-3 perf record.
  **Measure idle only**: three separate incidents of thermal throttling
  inflating post-gate inline captures by 10-30%.
- Debug hooks (env-gated, getenv cached in statics — mandatory pattern):
  MC_RNG_TRACE_FEATURE/MC_RNG_TRACE_FILE, MC_TRACE_WATCH, MC_SURF_DEBUG,
  MC_CARPET_TRACE, MC_SHAPE_TRACE, MC_SECTION_WATCH (raw section writes —
  catches writers bypassing level wrappers), MC_BG_THREADS (harness worker
  count), `--block-trace` (per-write feature attribution).
